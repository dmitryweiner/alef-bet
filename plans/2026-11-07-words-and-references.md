## 1. При открытии приложения — «Алфавит»

## 2. При каждом открытии «Алфавита» и «Некудот» ничего не выбрано

- `src/app.ts`: вместо `selected`, `selectedMark` и `detailOpen` — один
  временный выбор открытого справочника: `selectedId: number | undefined`.
  Каждый переход на вкладку (по вкладке, по адресу, «назад» в браузере)
  сбрасывает его в `undefined`. В localStorage не сохраняется.
- Нет выбора — нет блока `.detail` и ни одна карточка не `aria-pressed="true"`.
  Крестик сбрасывает выбор.
- Исключение — «Рассмотреть в алфавите» / «Повторить некудот» после раунда:
  они открывают вкладку сразу с описанием нужной буквы/знака.
- Тесты: при открытии каждого справочника нет описания и выбранных карточек;
  выбрал карточку → ушёл в игру → вернулся: снова ничего не выбрано; то же
  при переходе алфавит → некудот. Тесты, которые сейчас ждут открытое
  описание сразу, сначала кликают по карточке.

## 3. «Некудот»: группы по прочтению

Вместо разделов «Гласные / С буквами ו и י / Сокращённые / Другие» — группы
по звуку; внутри группы: простой знак, затем с ו/י, затем сокращённый:

| Группа | Знаки |
| --- | --- |
| Звук «а» | камац, патах, хатаф-патах |
| Звук «э» | цере, сеголь, цере малэ, хатаф-сеголь |
| Звук «и» | хирик, хирик малэ |
| Звук «о» | холам, холам малэ, хатаф-камац |
| Звук «у» | кубуц, шурук |
| Шва и другие знаки | шва, дагеш, точка шин, точка син |

## 4. «Как читать»: исправить גור

`גּוֹר` (холам малэ, «гор») → `גּוּר` (шурук, «гур») — щенок. Тест: слово
`גּוּר` читается «гур», `גּוֹר` в словаре нет.

## 5. «Как читать»: слова из трёх согласных

### Модель слова

Сейчас слово — ровно «буква + гласный + буква» (`syllable(first, vowel, last)`).
Обобщаю до последовательности «буква + огласовка»:

- Словарь записывается обычными словами с огласовкой, с ожидаемым чтением и
  переводом: `['יֶלֶד', 'елед', 'мальчик']`. Старые 121 слово переводятся в ту же
  запись (`['דָּג', 'даг', 'рыба']`).
- Разбор слова: буква (с дагешем или точкой шин/син) и её знак; `וֹ`, `וּ` и
  `ִי`, `ֵי` после буквы без своего гласного — холам малэ, шурук, хирик малэ,
  цере малэ (как сейчас). `י` или `ו` со своим гласным — согласные («й», «в»).
- Правила чтения (расширение нынешних):
  - ב, כ, פ: с дагешем — «б», «к», «п», без — «в», «х», «ф» (в том числе в
    середине: חָלָב «халав», סֵפֶר «сефер»). В остальных буквах дагеш на чтение
    не влияет (אִמָּא «има», חַלּוֹן «халон»).
  - א и ע не читаются; ה в конце не читается, в остальных местах — «х».
  - ל без гласного (в конце) — «ль»; с гласным — «л» (כֶּלֶב «келев»).
  - Шва в начале слова не читается (זְמַן «зман», כְּבָר «квар»); других шва в
    словаре нет.
  - Патах под конечными ח, ע (патах гнува) читается перед буквой:
    פָּתוּחַ «патуах», יוֹדֵעַ «йодеа».
  - `י` без гласного после гласного — «й» (מָתַי «матай»).
  - Русская запись как сейчас: «я», «е», «ю» вместо «йа», «йэ», «йу»;
    «е» вместо «э» после согласного, «э» в начале и после немой буквы
    (רָעֵב «раэв»).
- Объяснение после ответа — по буквам и знакам в порядке написания:
  «י — «й», сеголь — «э», ל — «л», сеголь — «э», ד — «д»». Для патаха гнува —
  пометка «читается перед буквой». В `app.ts` перестаю отличать знак по
  индексу `i === 1`: у части будет `kind: 'letter' | 'mark'`.
- Неверные варианты: как сейчас — два с заменой гласного звука (теперь в
  одном случайном слоге) и ещё один: замена гласного или путаница одной
  буквы (בּ/ב, כּ/כ, פּ/פ, ד/ר, ג/נ, ח/ת, שׁ/שׂ…). Все четыре варианта разные.
- Раунд: проходы по гласным остаются; слово подходит гласному, если
  этот знак есть в слове. «Повторить некудот» открывает первый гласный
  слова. Короткие и трёхбуквенные слова — в одном общем пуле.

### Тесты (`reading.test.ts`)

- Для каждого слова словаря чтение по правилам совпадает с записанным —
  это ловит опечатки в огласовке.
- Правила по отдельности: ב/כ/פ в середине, немые א/ע/ה, «ль»/«л», шва в
  начале, патах гнува, конечная `י`, «е»/«э».
- В слове 2–3 согласных (плюс ו/י полных гласных); конечные формы в конце;
  дагеш в ב, כ, פ в начале; холам не стоит на ש (в любом месте).
- Не меньше 100 слов из трёх согласных, слова и чтения без повторов.
- Варианты: четыре разных, верный среди них; минимум два отличаются от
  верного только гласным.
