# [Алеф-бет](https://dmitryweiner.github.io/alef-bet/)

Исходный код версии 8, опубликованной 19 октября 2026 года.
Коммит: 8f00ced2791bccaab4d9fac806f624491ca3acae

## Запуск

Нужен Node.js 24 (версия указана в `.node-version`; с fnm: `fnm use`).

```sh
npm ci
npm run dev      # дев-сервер
npm test         # юнит-тесты
npm run build    # проверка типов и сборка в dist/
npm run preview  # просмотр собранной версии
```

Приложение статическое: содержимое `dist/` можно выложить на любой
статический хостинг. GitHub Actions собирает и тестирует проект на каждый
push и PR, а пуш в `main` публикует сборку на GitHub Pages.

Правила разработки (TDD, структура модулей) — в [AGENTS.md](AGENTS.md).

## Файлы

- index.html — страница, режимы и настройки игры.
- src/ — исходный код на TypeScript и тесты (`*.test.ts`).
- src/style.css — оформление и адаптация для телефона.
- src/fonts/handwriting.ttf — рукописный шрифт Playpen Sans Hebrew.
- src/fonts/print-sans.ttf — Noto Sans Hebrew, без засечек.
- src/fonts/print-serif.ttf — Noto Serif Hebrew, с засечками.
- public/*LICENSE.txt — лицензии шрифтов; сохраняйте при распространении.
- public/manifest.webmanifest, public/*.png — манифест и иконки PWA.

## Текущие возможности

- «Угадай букву» — выбор названия из вариантов.
- «Впиши название» — ввод названия по-русски, проверка кнопкой или Enter.
  Регистр и лишние пробелы не важны; принимаются распространённые варианты
  названий. Для конечных форм добавьте «софит».
- «Найди пару» — сопоставление печатных и письменных букв.
- «Алфавит» — справочник без настроек и статистики: все буквы и конечные формы,
  звук, название на иврите, пример слова, место в алфавите, числовое значение,
  ссылки на конечную/обычную форму и на похожие по виду и звучанию буквы.
- У каждого режима свой адрес: `#guess`, `#type`, `#pairs`, `#alphabet`.
- Работает без интернета (PWA): после первого открытия всё нужное лежит в кэше,
  приложение можно установить на телефон. Новая версия включается, когда
  закрыты все вкладки со старой.
- Все 22 буквы, 5 конечных форм или оба набора вместе.
- Печатное, письменное или смешанное начертание; случайный печатный шрифт.
- Подсказки со звуками и ассоциациями; отдельный учёт самостоятельных
  ответов, ответов с подсказкой и ошибок.
- Автопереход (по умолчанию включён): 1,5 секунды после верного ответа,
  3 секунды после ошибки. Есть пауза и ручной переход.
- Показ трёх начертаний правильной буквы на месте большой буквы после
  ответа — включается галочкой, по умолчанию выключен.

- Статистика по каждой букве: буквы, в которых чаще ошибаешься, и буквы,
  которые давно не встречались, показываются в панели «Твоя статистика»
  (на телефоне — внизу страницы) и чаще попадают в новый раунд.
- В localStorage сохраняются настройки (наборы, начертание, галочки),
  статистика по буквам и результаты последних 200 раундов. Если localStorage
  недоступен, игра работает как раньше, без сохранения.
- Кнопка «Сбросить статистику» в настройках (с подтверждением) удаляет
  статистику по буквам и историю раундов; настройки сохраняются.
