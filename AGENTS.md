# Agents guide

Алеф-бет — статическая игра для изучения ивритского алфавита.
TypeScript + Vite, тесты на Vitest. Интерфейс на русском.

## Команды

Node.js — версия из `.node-version` (`fnm use`).

- `npm ci` — установить зависимости.
- `npm run dev` — дев-сервер.
- `npm test` — юнит-тесты (`npm run test:watch` — в режиме наблюдения).
- `npm run typecheck` — проверка типов.
- `npm run build` — проверка типов и сборка в `dist/`.

CI (`.github/workflows/ci.yml`) запускает typecheck, тесты и сборку на каждый push и PR;
пуш в `main` публикует `dist/` на GitHub Pages.

## Разработка через TDD — обязательно

Любое изменение поведения делается по циклу red → green → refactor:

1. Сначала напиши падающий тест, описывающий новое поведение или воспроизводящий баг.
   Запусти его и убедись, что он падает по ожидаемой причине.
2. Напиши минимальный код, чтобы тест прошёл.
3. Отрефактори, не ломая тесты.

Изменения без теста не принимаются. Перед завершением работы `npm run typecheck`,
`npm test` и `npm run build` должны проходить.

## Структура

- `src/letters.ts` — данные алфавита и наборы букв.
- `src/names.ts` — проверка введённых названий букв.
- `src/stats.ts` — статистика по буквам: ошибки, давность показа, веса.
- `src/selection.ts` — подбор букв в раунд с учётом статистики; `seededRandom` для тестов.
- `src/round.ts` — создание вопросов раунда.
- `src/storage.ts` — сохранение настроек, статистики и результатов в localStorage
  (с валидацией; повреждённые данные заменяются значениями по умолчанию).
- `src/format.ts` — форматирование текста (склонения, «N дней назад»).
- `src/routes.ts` — режимы и их адреса (`#guess`, `#type`, `#pairs`, `#alphabet`).
- `src/reference.ts` — справка о буквах для алфавита: название на иврите, пример слова,
  числовое значение, конечная форма, похожие по виду и звучанию буквы.
- `src/pwa.ts` — регистрация service worker; `src/sw-plugin.ts` — плагин Vite, который
  при сборке генерирует `sw.js` со списком всех файлов для работы без интернета.
- `src/app.ts` — DOM и игровой процесс; `src/main.ts` — точка входа.
- Тесты лежат рядом с кодом: `*.test.ts`. Тесты DOM используют jsdom
  (`// @vitest-environment jsdom`) и разметку из `index.html`.

## Соглашения

- Чистая логика — в отдельных модулях без DOM; время (`now`) и случайность (`Random`)
  передаются параметрами, чтобы их можно было подменить в тестах.
- Не меняй формат сохранённых данных без повышения версии в `src/storage.ts`
  и теста на миграцию/сброс.
